# Scientific and editorial review

Review date: **20 October 2026** in the user's local time zone. Some source checks continued on **21 October UTC**; individual audit records retain their actual check dates.

## Scope and approach

This pass reviews all thirteen projects and the profile pages for factual support, grammar, structure, terminology, assumptions, and consistency with implemented behavior. The [starting revisions](editorial-review-baseline.json) identify the reviewed state. Current guidance was corrected while historical search logs, scientific data, frozen analysis results, and upstream template copies retained their provenance.

Each project now links four companion documents: a glossary, an assumption register, a source-by-source reference audit, and a dated correction record. The registers distinguish literature evidence, project calculations, practical choices, and untested assumptions. Citations use descriptive author–year links and complete verified bibliographic fields. Dataset and software identities remain separate from article findings and reuse terms.

This is a focused correction pass. It does not establish exhaustive literature coverage, error-free software, independent biological replication, or professional validation. Some papers were accessible only through abstracts or metadata. A full-text audit label means relevant sections were inspected, not that every page and supplement received a complete appraisal.

## Verification and remaining work

Existing project tests, selected documented commands, and output comparisons were run as recorded in the individual reviews. The shared checker validates section order, links, review-file presence, and source-audit structure. It does not judge citation support or terminology quality; those received separate reading and source checks. A second reading identified and corrected errors in definitions of macro F1, sparse matrices, eigenvalues, replicate types, and exposure duration.

Preserved upstream template material is identified as historical context, not current product documentation. Immutable reports that use older wording are interpreted by the current correction notes. Source discrepancies in Pasilla labels and morphology concentration units remain unresolved rather than being silently replaced by guesses.

Further independent domain review and a reader walkthrough would still be useful. Before a consequential use, the relevant project needs an appropriate external evaluation and a scoped operational pilot. The [maintenance guide](../MAINTENANCE.md) describes how to continue this work without changing history silently.
