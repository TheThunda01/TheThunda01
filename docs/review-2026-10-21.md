# Portfolio review and maintenance

Review date: **21 October 2026**.

## What this review covers

This review revisits all thirteen projects: the questions they ask, the data and model assumptions behind them, the reported calculations, their references, and the way the results are explained. It also addresses the Windows problems found in the preceding completeness audit. The earlier review and source records remain available so the history is traceable.

The review used the code, saved data and outputs, original papers, official dataset documentation, and fresh computational checks. A central metadata check retrieved all 97 distinct PubMed records cited in the source audits; project-level checks considered the passages supporting the main claims. Metadata checks establish the identity of a reference, not whether it supports a conclusion. Each project records what was accessible and what was actually inspected.

These are AI-assisted reviews and reproductions of the existing demonstrations. They are not independent human adjudication, new biological experiments, or external validation of the models.

## Maintenance changes

- Checksum-protected text receives explicit line-ending rules so a Windows checkout does not silently change its bytes. The source checks remain in place.
- Surveillance writes generated text as UTF-8 and derives the chart's date label from the validated snapshot, rather than a fixed example date.
- Tests separate ordinary file-protection behavior from checks that specifically require symbolic links. Where Windows lacks that capability, the link-specific check reports a skip; Linux CI still exercises it.
- Review Compass's active package no longer pulls in unused template build dependencies. The documented static app is served directly, and its historical template material remains identified.
- The historical second-pass verification command now selects the original ten-project manifest. Current collection checks use all thirteen projects without requiring those newer projects to have older search histories.
- The early four-project branch is retained as historical context, with a clear note that the standalone repositories are the current projects. Its older layout is not merged into the profile.

## References and mathematics

The [profile reference recheck](reference-check-2026-10-21.json) records the organizational and reproducibility sources revisited in this pass. Project reviews separately record their biological and statistical evidence. Source access is not upgraded merely because a DOI resolves or metadata matches.

The current source inventory contains **209 mathematical expressions on 43 pages**. The earlier 204-expression record omitted two expressions in the enzyme README and three in its biology guide. All 209 were checked in GitHub's actual mathematical renderer without reported rendering errors; [the rendering record](math-rendering-checks.json) identifies the pages. Commands, field names, and the frozen GFP protocol retain their literal form. A displayed equation still needs a correct definition and an appropriate model assumption; successful rendering is only a presentation check.

## What remains open

The Pasilla sample-label discrepancy and morphology dose-unit ambiguity are documented, not silently resolved. Neither justifies relabeling source data. The case studies also retain their stated limits around external datasets, real experiments, independent use, and population generalization.

My personal learning checkpoints remain separate from these maintenance checks: explaining the GFP result, developing a follow-up I can defend, and understanding its failure cases. Passing tests or improving the writing does not complete those checkpoints.
